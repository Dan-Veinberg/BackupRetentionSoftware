# BackupRetentionSoftware
Download the full software [here](https://backupretentionsoftware.s3.us-west-1.amazonaws.com/BackupRetentionSoftware.zip).
Hello, this software is to be used with programs like freefilesync or robocopy that are very good at making copies of files but do not have a snapshot retention solution. Download the zip file, extract, and run the exe. Please watch the tutorial on how to setup an automated backup solution.
